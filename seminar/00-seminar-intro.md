# Attention 구조 — MHA부터 Linear Attention까지

> 기본 MHA에서 시작해 MQA · GQA · MLA, SWA · DSA · CSA/HCA · QSA, 그리고 Linear Attention과 하이브리드 구조까지 — 최근 LLM이 쓰는 Attention 구조를 차례로 살펴봅니다.

## 1. 무엇을, 어떻게 다루나

| 순서 | 주제 | 중심 질문 |
|---|---|---|
| 1부 · 제가 발표 | Attention과 KV cache — 저장을 줄이는 방법(MHA → MLA)과 읽기를 줄이는 방법(SWA → QSA) | 무엇을 저장하고, 얼마나 읽으며, 어떤 연산이 새로 생기는가? |
| 2부 · 공동 발표자 | Linear Attention — KV cache 대신 고정 크기 상태, 하이브리드 구조 | 과거를 고정 크기 상태에 담으면, 저장과 갱신은 어떻게 달라지는가? |

기법마다 **어떤 비용을 줄였고, 그 대신 무엇이 새로 생겼는지**를 봅니다. 1부는 토큰을 하나씩 생성하는 **decode** 기준이며, 실제 모델 설정으로 계산한 숫자로 비교합니다.

## 2. 제가 이 주제를 공부하게 된 이유

저는 **LLM inference 시뮬레이터와 roofline 모델**로 여러 시스템에서 LLM workload의 latency, 병목, 특성을 분석하고, 필요한 연산을 직접 모델링합니다. 그러려면 **"이 모델이 어떤 연산을 하고, 어떤 데이터를 얼마나 읽고 쓰는가"**를 알아야 합니다. Attention은 LLM의 핵심 구성 요소이고, 최근 모델마다 구조가 다양하게 바뀌고 있어 자세히 보게 되었습니다.

## 3. 함께 얻어 가고, 이어 가고 싶은 것

토큰 하나를 만들 때 일어나는 연산과 데이터 접근, 그리고 Attention 구조를 **연산량 · 저장량 · 읽고 쓰는 양 · 접근 패턴**으로 비교하는 기준을 가져가시면 좋겠습니다.

오늘 설명하는 연산과 데이터 이동을 기준으로, 여러 관점으로 확장해 볼 수 있을 것 같습니다.

- **SoC 모델링** — 반영할 연산과 데이터 이동
- **메모리 시스템** — 저장량과 접근 패턴
- **전력** — 데이터 이동과 재사용

이번 세미나를 계기로, 더 나아가 함께 협업할 수 있는 기회도 생기면 좋겠습니다.
