# Attention 구조 — MHA부터 Linear Attention까지

> MHA에서 시작해 MQA·GQA·MLA, Sparse Attention(SWA·DSA·CSA/HCA·QSA)구조까지, 최근 LLM의 Attention 구조가 어떻게 발전해 왔고, 연산과 메모리 관점에서 무엇이 달라졌는지 살펴봅니다.
 
## 1. 세미나에서 다룰 냉둉

| 순서 | 주제 | 중심 질문 |
|---|---|---|
| 1부 · 제가 발표 | Attention과 KV cache — 저장을 줄이는 방법(MHA → MLA)과 읽기를 줄이는 방법(SWA → QSA) | 무엇을 저장하고, 얼마나 읽으며, 어떤 연산이 새로 생기는가? |
| 2부 · 공동 발표자 | Linear Attention — KV cache 대신 고정 크기 상태, 하이브리드 구조 | 과거를 고정 크기 상태에 담으면, 저장과 갱신은 어떻게 달라지는가? |

각 Attention 구조가 **어떤 비용을 줄이기 위해 등장했고, 그 대신 어떤 새로운 비용이나 특성이 생겼는지**를 중심으로 살펴봅니다.

## 2. 저희가 이 주제를 공부하게 된 이유

저희는 LLM inference simulator와 roofline 모델을 활용해 다양한 시스템에서 **LLM workload의 latency와 bottleneck을 분석하고, 필요한 연산을 모델링하는 업무**를 하고 있습니다.
이러한 분석을 위해서는 **모델이 실제로 어떤 연산을 수행하고, 어떤 데이터를 얼마나 읽고 쓰는지** 이해나는 것이 중요합니다.
특히 attention은 LLM의 핵심 구성 요소이면서 최근 모델마다 다양한 구조가 적용되고 있어, 각 구조의 특징과 차이를 연산 및 메모리 관점에서 자세히 살펴보게 되었습니다.
이번 세미나에서는 그동안 공부하고 정리한 내용을 함께 공유하고자 합니다.


## 3. 함께 얻어 가고, 이어 가고 싶은 것

이번 세미나에서는 다양한 attention 구조를 **연산량·저장량·데이터 이동량·접근 패턴** 관점에서 살펴봅니다. 
이러한 내용이 LLM workload에 대한 이해를 넓히고, 나아가 **Soc 모델링, 메모리 시스템, 전력 등 각자의 업무 관점에서도 참고하거나 새로운 아이디어를 얻는 데** 도움이 되었으면 좋겠습니다. 
또한 이번 세미나가 서로 다른 관점에서 의견을 나누고, 향후 함께 논의하거나 협업할 수 있는 계기가 되었으며 합니다 :)
